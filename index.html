FIREARMS DIVISION HANDBOOK

Official LSPD Firearms Rules & Training Manual

Firearms Division مسئول ایجاد و حفظ استانداردهای مربوط به استفاده مسئولانه از تجهیزات Firearms در LSPD است.

اهداف اصلی

  • افزایش کیفیت Roleplay
  • ایجاد استاندارد یکسان برای تجهیزات
  • جلوگیری از استفاده غیرضروری از تجهیزات
  • افزایش مسئولیت‌پذیری Officers
  • حفظ ایمنی Civilians و Officers
  • جلوگیری از FailRP و Powergaming
Firearms برای افزایش کیفیت RP است، نه برای افزایش تعداد درگیری‌ها.

Head of Firearms

  • بالاترین مقام Firearms Division
  • تعیین سیاست‌های داخلی
  • نظارت بر Training
  • بررسی تخلفات مهم

Assistant / Deputy Head

  • کمک به Head of Firearms
  • نظارت بر Instructors

Firearms Instructor

  • آموزش قوانین
  • برگزاری Training
  • ارزیابی Officers

Firearms Officer

  • رعایت Handbook
  • نگهداری مسئولانه تجهیزات
  • گزارش Incident

هر Officer مسئول رفتار، تجهیزات و تصمیمات خود در چارچوب قوانین Department است.

  • رعایت Server Rules
  • رعایت Department Rules
  • رعایت Chain of Command
  • استفاده از تجهیزات فقط در Authorization
  • گزارش تجهیزات گم‌شده یا مشکل‌دار
  • گزارش Incidentهای مهم

Professional Conduct

  • رفتار حرفه‌ای
  • حفظ آرامش در موقعیت‌های تنش‌زا
  • رعایت دستورات فرماندهی
  • رفتار محترمانه با Civilians
  • جلوگیری از درگیری غیرضروری
RDM، FailRP، Powergaming، Metagaming و Combat Logging ممنوع هستند.

دسترسی به تجهیزات باید مطابق Rank، Training و Authorization تعیین‌شده باشد.

LEVEL 0 بدون دسترسی
LEVEL 1 Basic Equipment
LEVEL 2 Patrol Authorization
LEVEL 3 Special Authorization
LEVEL 4 Restricted Equipment

قانون کلی

داشتن Rank به‌تنهایی به معنی دسترسی به تمام تجهیزات نیست. Officer باید Training و Authorization لازم را نیز داشته باشد.

Basic Equipment

تجهیزات پایه برای انجام وظایف معمول Officer و Patrol استفاده می‌شوند.

  • Radio
  • Standard Duty Equipment
  • تجهیزات ارتباطی و شناسایی مجاز

Patrol Authorization

تجهیزات سطح Patrol تنها در صورتی قابل استفاده هستند که Officer مجوز و Training مربوطه را داشته باشد.

Equipment access must match Rank + Training + Authorization.

ایمنی مهم‌ترین اصل در استفاده از تجهیزات Firearms است.

  • تجهیزات باید همیشه تحت کنترل Officer باشند.
  • استفاده از تجهیزات باید مطابق قوانین Server باشد.
  • از استفاده نمایشی یا غیرضروری خودداری شود.
  • در صورت مشاهده مشکل تجهیزات، موضوع گزارش شود.
  • Officer باید قبل از اقدام شرایط موقعیت را ارزیابی کند.

Officer باید تا حد امکان از روش‌های مناسب برای کنترل موقعیت استفاده کند.

Communication → De-escalation → Control → Appropriate Response
Weapon ≠ First Option

نوع پاسخ باید متناسب با شرایط Roleplay و قوانین Server باشد.

Incidentهای مهم باید طبق سیستم داخلی Department ثبت و گزارش شوند.

گزارش باید شامل موارد زیر باشد:

  • Incident ID
  • Officer
  • Rank
  • Date / Time
  • Location
  • Incident Type
  • Description
  • Persons Involved
  • Evidence
  • Outcome

هیچ Officer نباید بدون Training مناسب از تجهیزات دارای Authorization خاص استفاده کند.

Training شامل:

  • آشنایی با Handbook
  • آشنایی با Equipment Authorization
  • آشنایی با Server Rules
  • شناخت مسئولیت‌های Officer
  • Certification Exam

نقض قوانین Firearms Division می‌تواند منجر به بررسی داخلی و اقدامات انضباطی شود.

  • استفاده بدون Authorization
  • استفاده غیرضروری از Equipment
  • عدم گزارش Incident
  • نقض Chain of Command
  • نقض Server Rules
هر تخلف باید طبق قوانین واقعی Server و Department بررسی شود.

من، Henry Fernandez، متعهد می‌شوم قوانین Server، Department و Firearms Division را رعایت کنم و مسئولیت رفتار و تجهیزات خود را بپذیرم.
