FIREARMS DIVISION HANDBOOK

Official Department Rules

01 — PURPOSE

واحد Firearms مسئول ایجاد، مدیریت و نظارت بر استانداردهای مربوط به تجهیزات و سلاح‌های مورد استفاده اعضای سازمان است.

اهداف اصلی

  • ایجاد RP حرفه‌ای و واقع‌گرایانه
  • جلوگیری از استفاده بی‌دلیل از تجهیزات
  • حفظ جان شهروندان و اعضای Department
  • جلوگیری از FailRP و Powergaming
  • کنترل دسترسی به تجهیزات
  • ثبت و کنترل تجهیزات سازمان
Firearms برای افزایش کیفیت RP است، نه برای افزایش تعداد درگیری‌ها.

02 — CHAIN OF COMMAND

Head of Firearms

  • بالاترین مقام واحد
  • تعیین سیاست‌های داخلی
  • تأیید آموزش‌ها
  • بررسی تخلفات مهم

Assistant / Deputy Head

  • کمک به Head of Firearms
  • نظارت بر Instructors
  • بررسی عملکرد اعضا

Firearms Instructor

  • آموزش قوانین
  • برگزاری آزمون
  • ارزیابی اعضای جدید

Firearms Officer

  • رعایت کامل Handbook
  • نگهداری تجهیزات
  • گزارش حوادث

Trainee

عضو در دوره آموزشی با دسترسی محدود و تحت نظارت Instructor.

03 — RESPONSIBILITIES

  • رعایت Server Rules
  • رعایت Department Rules
  • رعایت Chain of Command
  • نگهداری مسئولانه تجهیزات
  • گزارش حوادث
  • عدم استفاده خارج از Authorization
  • جلوگیری از تشدید غیرضروری موقعیت

04 — MEMBERSHIP REQUIREMENTS

  • Rank موردنیاز Department
  • سابقه مناسب RP
  • نداشتن تخلفات جدی
  • قبولی آزمون تئوری
  • آشنایی با Server Rules
  • آشنایی با FearRP / Value of Life
  • تأیید Instructor
  • تأیید Head of Firearms

05 — CODE OF CONDUCT

  • Professional بودن
  • خونسردی
  • جلوگیری از درگیری غیرضروری
  • رعایت دستورات فرماندهی
  • رفتار محترمانه با Civilians
  • ارائه گزارش دقیق
RDM، FailRP، Powergaming، Metagaming و Combat Logging ممنوع است.

06 — EQUIPMENT POLICY

تمام تجهیزات سازمانی باید ثبت شده و مطابق Rank و Authorization استفاده شوند.

07 — WEAPON CLASSIFICATION

CLASS A Sidearms
CLASS B Patrol Long Guns
CLASS C Shotguns
CLASS D Rifles
CLASS E Restricted / Special

08 — WEAPON AUTHORIZATION

LEVEL 0 بدون دسترسی
LEVEL 1 تجهیزات پایه
LEVEL 2 Patrol
LEVEL 3 Special Authorization
LEVEL 4 Restricted / Command

09 — RP WEAPON USE POLICY

استفاده از تجهیزات باید همیشه دارای RP Reason مناسب باشد.

  • چه اتفاقی افتاده؟
  • تهدید چه بوده؟
  • چرا واکنش مسلحانه مطرح شده؟
  • آیا گزینه کم‌تنش‌تری وجود داشته؟
  • آیا Server Rules رعایت شده؟
Weapon ≠ First Option

10 — ESCALATION POLICY

Communication → De-escalation → Control → Appropriate Response

11 — ARMED INCIDENT POLICY

  1. حفظ کیفیت RP
  2. حفظ جان Civilians
  3. رعایت Server Rules
  4. جلوگیری از تشدید غیرضروری
  5. هماهنگی با Command
  6. ثبت Incident

12 — VEHICLE POLICY

تجهیزات Vehicle باید مطابق Vehicle Loadout ثبت‌شده باشد.

13 — INVENTORY & ACCOUNTABILITY

هر عضو مسئول تجهیزاتی است که دریافت کرده است.

Lost / Missing / Damaged / Unauthorized Transfer باید فوراً گزارش شود.

14 — INCIDENT REPORT

گزارش باید شامل موارد زیر باشد:

  • Incident ID
  • Officer
  • Rank
  • Date / Time
  • Location
  • Incident Type
  • Description
  • Persons Involved
  • Evidence
  • Outcome

15 — DISCIPLINARY SYSTEM

Minor Verbal Warning
Moderate Written Warning / Suspension
Major Suspension / Removal
Critical Removal + Command Review

16 — TRAINING PROGRAM

Server Rules Department Rules FearRP / Value of Life Weapon Authorization Equipment Accountability De-escalation Incident Reporting Professional Communication Scenario-Based RP

17 — TRAINING SCENARIOS

Scenario A — Verbal Conflict

حفظ Professionalism و جلوگیری از Escalation.

Scenario B — Suspicious Situation

جمع‌آوری اطلاعات RP، Communication و جلوگیری از واکنش عجولانه.

Scenario C — Equipment Check

Officer باید تجهیزات، Authorization و وضعیت Inventory را توضیح دهد.

18 — OFFICER OATH

من، Henry Fernandez، متعهد می‌شوم قوانین Server، Department و Firearms Division را رعایت کنم، از اختیارات خود سوءاستفاده نکنم، کیفیت RP را در اولویت قرار دهم و مسئولیت تجهیزات و رفتار خود را بپذیرم.

19 — FINAL POLICY

تمام اعضای Firearms موظف‌اند آخرین نسخه Handbook را مطالعه کنند. عدم آگاهی از قوانین، دلیل قابل قبول برای نقض آنها نیست.

Professionalism First Roleplay First Accountability Always

2. بالاترین مقام Firearms Division چیست؟

3. استفاده از Restricted Equipment بدون Authorization:

4. در صورت گم‌شدن تجهیزات چه باید کرد؟

5. Metagaming چیست؟

6. Weapon Is Not The First Option یعنی چه؟

7. ترتیب صحیح مدیریت موقعیت چیست؟

8. Officer مسئول تجهیزات تحویل‌گرفته‌شده است؟

9. یک Civilian با Officer بحث لفظی می‌کند اما تهدید مشخصی وجود ندارد. بهترین رویکرد چیست؟

11. یک Officer دیگر از تو می‌خواهد تجهیزاتی را که برای Rank او مجاز نیست در اختیارش قرار دهی. چه می‌کنی؟
