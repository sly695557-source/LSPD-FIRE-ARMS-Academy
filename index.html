ACADEMY HANDBOOK

Official Academy Standards

01 — PURPOSE

هدف Academy ایجاد یک استاندارد مشخص برای رفتار حرفه‌ای، کیفیت Roleplay، مسئولیت‌پذیری و رعایت قوانین Server است.

  • ایجاد Roleplay حرفه‌ای و منظم
  • رعایت قوانین Server
  • حفظ کیفیت تعاملات
  • مسئولیت‌پذیری Officers
  • جلوگیری از FailRP

02 — CHAIN OF COMMAND

تمام اعضای Department باید ساختار فرماندهی را رعایت کنند.

Head of Academy

مسئول نظارت کلی بر Academy و استانداردهای آموزشی.

Assistant / Deputy

همکاری با Head و نظارت بر عملکرد Instructors.

Instructor

مسئول آموزش، برگزاری آزمون و ارزیابی اعضا.

Officer

مسئول رعایت قوانین و دستورهای Department.

03 — CODE OF CONDUCT

رفتار حرفه‌ای یکی از اصلی‌ترین استانداردهای LSPD است.

  • احترام به سایر بازیکنان
  • حفظ آرامش در موقعیت‌های تنش‌زا
  • رعایت Chain of Command
  • عدم سوءاستفاده از مقام
  • رعایت قوانین Server
  • رفتار حرفه‌ای در تمامی شرایط

04 — ROLEPLAY STANDARDS

کیفیت RP باید در تمام تعاملات حفظ شود.

  • FailRP ممنوع است.
  • Powergaming ممنوع است.
  • Metagaming ممنوع است.
  • Combat Logging ممنوع است.
  • استفاده از اطلاعات OOC برای تصمیم IC ممنوع است.
  • تمام تصمیمات باید با منطق RP هماهنگ باشند.

05 — PROFESSIONAL COMMUNICATION

نحوه ارتباط Officers با Civilians و سایر اعضای Department باید حرفه‌ای و محترمانه باشد.

  • استفاده از لحن محترمانه
  • گوش‌دادن به صحبت طرف مقابل
  • جلوگیری از بحث غیرضروری
  • ارائه دستورهای واضح
  • حفظ آرامش هنگام اختلاف

06 — INCIDENT REPORT

حوادث مهم باید به شکل منظم گزارش شوند.

  • Incident ID
  • Officer Name
  • Rank
  • Date / Time
  • Location
  • Incident Type
  • Description
  • Persons Involved
  • Evidence
  • Outcome

07 — DISCIPLINARY POLICY

نقض قوانین می‌تواند باعث بررسی عملکرد عضو شود.

  • Warning
  • Training Review
  • Temporary Suspension
  • Rank Review
  • Departmental Review

نوع برخورد با توجه به شدت تخلف و قوانین Server تعیین می‌شود.

08 — OFFICER RESPONSIBILITIES

هر Officer مسئول رفتار و عملکرد خود است.

  • رعایت Server Rules
  • رعایت Department Rules
  • رعایت Chain of Command
  • گزارش حوادث
  • حفظ اطلاعات داخلی Department
  • رفتار حرفه‌ای

09 — TRAINING

آموزش Officers باید مرحله‌ای و قابل ارزیابی باشد.

  1. Orientation
  2. Handbook Review
  3. Scenario Training
  4. Instructor Evaluation
  5. Certification

10 — OFFICER OATH

من، Henry Fernandez، متعهد می‌شوم قوانین Server و Department را رعایت کنم، رفتار حرفه‌ای داشته باشم و مسئولیت عملکرد خود را بپذیرم.
