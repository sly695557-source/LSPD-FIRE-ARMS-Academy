Officer باید در تعامل با اعضای Department و سایر افراد رفتار محترمانه و حرفه‌ای داشته باشد.

دسترسی به تجهیزات باید مطابق Rank، Training و Authorization تعیین‌شده باشد.

LEVEL 0 — بدون دسترسی
LEVEL 1 — Basic Equipment
LEVEL 2 — Patrol Authorization
LEVEL 3 — Special Authorization
LEVEL 4 — Restricted Equipment

قانون کلی

داشتن Rank به‌تنهایی به معنی دسترسی به تمام تجهیزات نیست. Officer باید Training و Authorization لازم را نیز داشته باشد.

Basic Equipment

تجهیزات پایه برای وظایف معمول و Patrol استفاده می‌شوند.

  • Radio
  • Standard Duty Equipment
  • تجهیزات ارتباطی مجاز
  • تجهیزات شناسایی مجاز

Patrol Authorization

تجهیزات سطح Patrol تنها زمانی قابل استفاده هستند که Officer مجوز و Training مربوطه را داشته باشد.

Equipment Access = Rank + Training + Authorization

Safety مهم‌ترین اصل در Firearms Division است.

  • تجهیزات باید تحت کنترل مسئولانه Officer باشند.
  • قوانین Server و Department باید رعایت شوند.
  • از استفاده نمایشی یا غیرضروری خودداری شود.
  • مشکلات تجهیزات باید گزارش شوند.
  • شرایط موقعیت باید قبل از تصمیم مهم ارزیابی شود.
  • هر Authorization باید مطابق Training استفاده شود.

Officer باید تا حد امکان از روش مناسب برای کنترل موقعیت استفاده کند.

Communication → De-escalation → Control → Appropriate Response

اصل مهم

Weapon ≠ First Option

نوع پاسخ باید متناسب با شرایط Roleplay و قوانین Server باشد.

Incidentهای مهم باید طبق سیستم داخلی Department ثبت و گزارش شوند.

گزارش باید شامل موارد زیر باشد:

  • Incident ID
  • Officer
  • Rank
  • Date / Time
  • Location
  • Incident Type
  • Description
  • Persons Involved
  • Evidence
  • Outcome

هیچ Officer نباید بدون Training مناسب از تجهیزات دارای Authorization خاص استفاده کند.

Training شامل:

  • آشنایی با Handbook
  • آشنایی با Equipment Authorization
  • آشنایی با Server Rules
  • شناخت مسئولیت‌های Officer
  • Safety Awareness
  • Certification Exam

نقض قوانین Firearms Division می‌تواند منجر به بررسی داخلی و اقدامات انضباطی مطابق قوانین Department شود.
