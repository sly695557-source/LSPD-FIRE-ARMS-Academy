تمام اعضا موظف‌اند:

  • رفتار حرفه‌ای داشته باشند.
  • Chain of Command را رعایت کنند.
  • با Civilians محترمانه رفتار کنند.

  • هر Incident مهم را گزارش کنند.
  • قوانین Server را رعایت کنند.
  • کیفیت RP را در اولویت قرار دهند.

LOST / MISSING / DAMAGED / UNAUTHORIZED TRANSFER

باید بلافاصله Supervisor مطلع شود.

پنهان‌کردن تجهیزات مفقودشده تخلف جدی محسوب می‌شود.

استفاده از تجهیزات مسلحانه باید دارای Reasonable RP Justification باشد.

Officer باید بتواند توضیح دهد:

  • چه اتفاقی رخ داده؟
  • سطح تهدید چه بوده؟
  • چرا این واکنش در RP منطقی بوده؟
  • آیا امکان De-escalation وجود داشته؟
  • آیا Server Rules رعایت شده است؟
A WEAPON IS NOT THE FIRST OPTION.

توهین، اختلاف لفظی یا فرار ساده به‌تنهایی دلیل کافی برای تشدید موقعیت نیست.

COMMUNICATION ↓ DE-ESCALATION ↓ CONTROL ↓ APPROPRIATE RESPONSE

هدف اصلی، جلوگیری از Escalation غیرضروری است.

اولویت‌ها:

  1. حفظ کیفیت RP
  2. حفظ جان Civilians
  3. رعایت Server Rules
  4. هماهنگی با سایر Units
  5. رعایت Chain of Command
  6. ثبت Incident

پس از حادثه، در صورت درخواست Supervisor، Incident Report باید تکمیل شود.

  • از Radio Protocol استفاده کنید.
  • پیام‌ها را کوتاه و واضح نگه دارید.
  • از Spam جلوگیری کنید.
  • اطلاعات مهم را به Units مربوطه منتقل کنید.
  • از اطلاعات OOC در IC استفاده نکنید.

ممنوع:

  • ❌ Metagaming
  • ❌ استفاده از اطلاعات Discord در RP
  • ❌ Radio Spam
  • ❌ ارتباط غیرحرفه‌ای
