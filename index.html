LSPD FIREARMS HANDBOOK

01 — PURPOSE ▼

Firearms Academy با هدف ایجاد استاندارد مشخص برای آموزش، ایمنی، مسئولیت‌پذیری و استفاده صحیح از تجهیزات ایجاد شده است.

اهداف اصلی

  • آموزش اصول ایمنی
  • شناخت قوانین Department
  • شناخت Authorization
  • آمادگی برای Certification
  • افزایش مسئولیت‌پذیری Officer
02 — CHAIN OF COMMAND ▼

تمامی Officerها باید ساختار Chain of Command را رعایت کنند.

  • Head
  • Deputy / Assistant
  • Command
  • Instructor
  • Officer

مسائل مربوط به Training، Authorization و Discipline باید از مسیر مناسب پیگیری شوند.

03 — OFFICER RESPONSIBILITIES ▼
  • رعایت Server Rules
  • رعایت Department Rules
  • رعایت Firearms Policy
  • رعایت Chain of Command
  • گزارش Incidentهای مهم
  • حفظ Professionalism
  • رعایت Authorization
  • شرکت در Trainingهای لازم
04 — CODE OF CONDUCT ▼
  • Professionalism
  • Respect
  • Discipline
  • Accountability
  • Teamwork
  • Integrity

Officer باید در تمام شرایط رفتاری حرفه‌ای و مسئولانه داشته باشد.

05 — WEAPON AUTHORIZATION ▼

دسترسی به تجهیزات باید مطابق Rank، Training و Authorization تعیین‌شده باشد.

LEVEL 0

بدون دسترسی

LEVEL 1

Basic Equipment

LEVEL 2

Patrol Authorization

LEVEL 3

Special Authorization

LEVEL 4

Restricted Equipment

قانون کلی

داشتن Rank به‌تنهایی به معنی دسترسی به تمام تجهیزات نیست. Officer باید Training و Authorization لازم را نیز داشته باشد.

06 — BASIC & PATROL EQUIPMENT ▼

Basic Equipment

تجهیزات پایه برای انجام وظایف معمول Officer و Patrol استفاده می‌شوند.

  • Radio
  • Standard Duty Equipment
  • تجهیزات ارتباطی مجاز
  • تجهیزات شناسایی مجاز

Patrol Authorization

تجهیزات سطح Patrol تنها در صورتی قابل استفاده هستند که Officer مجوز و Training مربوطه را داشته باشد.

Equipment access must match Rank + Training + Authorization.

07 — FIREARMS SAFETY ▼

ایمنی مهم‌ترین اصل در Firearms Academy است.

  • تجهیزات باید همیشه تحت کنترل Officer باشند.
  • استفاده از تجهیزات باید مطابق قوانین Server باشد.
  • از استفاده نمایشی یا غیرضروری خودداری شود.
  • در صورت مشاهده مشکل تجهیزات، موضوع گزارش شود.
  • Officer باید قبل از هر اقدام شرایط موقعیت را ارزیابی کند.
  • استفاده از تجهیزات باید متناسب با شرایط Roleplay باشد.
08 — ESCALATION POLICY ▼

Officer باید تا حد امکان از روش‌های مناسب برای کنترل موقعیت استفاده کند.

Response Model

Communication → De-escalation → Control → Appropriate Response

Weapon ≠ First Option

نوع پاسخ باید متناسب با شرایط Roleplay و قوانین Server باشد.

09 — INCIDENT REPORT ▼

Incidentهای مهم باید طبق سیستم داخلی Department ثبت و گزارش شوند.

گزارش باید شامل موارد زیر باشد:

  • Incident ID
  • Officer
  • Rank
  • Date / Time
  • Location
  • Incident Type
  • Description
  • Persons Involved
  • Evidence
  • Outcome
10 — TRAINING & CERTIFICATION ▼

هیچ Officer نباید بدون Training مناسب از تجهیزات دارای Authorization خاص استفاده کند.

Training شامل:

  • آشنایی با Handbook
  • آشنایی با Equipment Authorization
  • آشنایی با Server Rules
  • شناخت مسئولیت‌های Officer
  • Certification Exam
11 — VIOLATIONS & DISCIPLINE ▼

نقض قوانین Firearms Division می‌تواند منجر به بررسی داخلی و اقدامات انضباطی شود.

  • عدم رعایت Firearms Policy
  • استفاده بدون Authorization
  • عدم رعایت Training
  • عدم رعایت Department Rules
  • رفتار غیرحرفه‌ای
  • گزارش نادرست Incident
12 — ROLEPLAY & SERVER RULES ▼
  • رعایت Roleplay
  • عدم استفاده از اطلاعات خارج از Roleplay
  • عدم تحمیل اقدامات غیرمنطقی
  • عدم Combat Logging
  • رعایت قوانین عمومی Server
13 — OFFICER ACCOUNTABILITY ▼

هر Officer مسئول اقدامات و تصمیمات خود است.

  • پذیرش اشتباهات
  • گزارش صحیح
  • همکاری با Internal Review
  • رعایت دستورات قانونی Command
  • حفظ اطلاعات داخلی Department
14 — FINAL CERTIFICATION ▼

برای دریافت Certification، Officer باید Handbook را مطالعه کرده، Trainingهای لازم را تکمیل کرده و Assessment مربوطه را با موفقیت پشت سر بگذارد.

15 — OFFICER OATH ▼

Officer متعهد می‌شود قوانین Server، Department و Firearms Academy را رعایت کند، مسئولیت اقدامات خود را بپذیرد و در تمام شرایط رفتار حرفه‌ای داشته باشد.
