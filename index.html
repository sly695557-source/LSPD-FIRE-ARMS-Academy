  • قوانین Server را رعایت کنند.

استفاده از تجهیزات مسلحانه باید دارای Reasonable RP Justification باشد.

Officer باید بتواند توضیح دهد:

  • چه اتفاقی رخ داده؟
  • سطح تهدید چه بوده؟
  • چرا این واکنش در RP منطقی بوده؟
  • آیا امکان De-escalation وجود داشته؟
  • آیا Server Rules رعایت شده است؟
A WEAPON IS NOT THE FIRST OPTION.

توهین، اختلاف لفظی یا فرار ساده به‌تنهایی دلیل کافی برای تشدید موقعیت نیست.

مدیریت موقعیت‌ها باید تا حد امکان مرحله‌ای باشد:

COMMUNICATION
↓ DE-ESCALATION
↓ CONTROL
↓ APPROPRIATE RESPONSE

هدف اصلی، جلوگیری از Escalation غیرضروری است.

در یک Armed Incident اولویت‌ها:

  1. حفظ کیفیت RP
  2. حفظ جان Civilians
  3. رعایت Server Rules
  4. هماهنگی با سایر Units
  5. رعایت Chain of Command
  6. ثبت Incident

پس از حادثه، در صورت درخواست Supervisor، Incident Report باید تکمیل شود.

  • از Radio Protocol استفاده کنند.
  • پیام‌ها را کوتاه و واضح نگه دارند.
  • از Spam جلوگیری کنند.
  • اطلاعات مهم را به Units مربوطه منتقل کنند.
  • از اطلاعات OOC در IC استفاده نکنند.

❌ Radio Spam
